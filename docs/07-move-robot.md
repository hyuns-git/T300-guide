# 07. 같은 층에서 로봇 움직이기

이 문서의 명령은 **로봇을 실제로 움직입니다.** 조회(04 문서)와 달리 사람이나 물건과 부딪힐 수 있습니다. 엘리베이터는 쓰지 않고, 로봇이 이미 올라가 있는 맵 안에서 지점 사이를 움직이는 것까지만 다룹니다.

## 시작하기 전에 (모두 충족해야 합니다)

1. 로봇 옆에 사람이 있고, 그 사람이 **로봇의 물리 비상정지 버튼에 손이 닿습니다.** 이 문서에 나오는 취소 명령은 보조 수단입니다. 정지는 비상정지 버튼으로 합니다.
2. 이동 경로에 사람, 물건, 문턱, 계단 가장자리가 없고, 사람들이 지나다니지 않는 시간입니다.
3. 로봇이 있는 층과 맵이 같습니다. 로봇의 실제 층을 눈으로 확인하세요. 04 문서에서 본 것처럼 `get-position`의 `floor` 값은 믿지 마세요.
4. 처음에는 짐을 싣지 않습니다.
5. 같은 건물의 관리 주체나 로봇 담당자가 이 시험을 알고 있습니다.

## 명령 세 개

`app/move.py`는 조회 코드와 따로 만들었습니다. 세 가지 안전장치가 있습니다.

- 기본은 **연습 실행**입니다. 무엇을 보낼지 화면에 보여 주기만 하고 아무것도 보내지 않습니다.
- 실제로 보내려면 `--send`를 붙이고, 이어서 나오는 질문에 `MOVE`라고 입력해야 합니다.
- 보낸 명령은 `t300.db`의 `call_log` 테이블에 성공과 실패 모두 남습니다.

### 1. 지점으로 보내기

먼저 연습 실행으로 무엇을 보낼지 봅니다.

```
python -m app.move call --sn ABCDEFG0123456 --point 3F-A
```

화면에는 로봇의 현재 맵 이름, 지점 이름, 지점 종류(`table`이나 `parking`)와 보낼 JSON이 나옵니다. 맵 이름과 지점 종류는 직접 적지 않고 로봇이 지금 올라가 있는 맵에서 읽어 옵니다. 그래서 다른 층 지점이나 없는 지점 이름을 넣으면 보내기 전에 막힙니다.

내용이 맞으면 같은 명령에 `--send`를 붙입니다.

```
python -m app.move call --sn ABCDEFG0123456 --point 3F-A --send
```

`로봇이 실제로 움직입니다. 계속하려면 MOVE 라고 입력하세요:`가 나오면 `MOVE`를 입력합니다. 다른 글자를 입력하면 아무것도 보내지 않고 끝납니다. 요청에는 `do_not_queue: true`가 들어 있어서, 로봇이 바로 갈 수 없는 상태이면 큐에 쌓이지 않고 실패합니다. 나중에 갑자기 움직이는 일을 막으려는 것입니다.

성공하면 응답에 `task_id`가 옵니다. 이동 중에는 다른 CMD 창에서 위치를 볼 수 있습니다.

```
python -m app.pudu get-position --sn ABCDEFG0123456
```

### 2. 충전기로 복귀

```
python -m app.move recharge --sn ABCDEFG0123456
python -m app.move recharge --sn ABCDEFG0123456 --send
```

푸두의 충전기 복귀 호출은 GET 방식인데도 로봇을 움직입니다. 그래서 이 명령도 같은 확인 절차를 거칩니다.

### 3. 호출 작업 취소

```
python -m app.move cancel --sn ABCDEFG0123456
```

이 키로 보낸 호출 작업 중 끝나지 않은 것을 취소합니다. 안전을 위한 명령이라 확인 질문 없이 바로 보냅니다. 푸두 문서는 취소를 호출을 보낸 키와 같은 키로 해야 한다고 적고 있습니다.

**이 취소가 이동 중인 로봇을 즉시 멈추는지는 문서에 적혀 있지 않고 확인하지 못했습니다.** 문서의 다른 `CancelTask`는 FlashBot 전용이어서 T300에는 쓸 수 없습니다. 멈춰야 할 때는 비상정지 버튼을 먼저 누르세요.

## 시험 순서 제안

1. 연습 실행으로 화면 내용을 확인합니다.
2. 로봇에서 2에서 3미터 정도 떨어진 지점을 고릅니다.
3. 비상정지 옆에 사람이 선 상태에서 `--send`로 한 번 보냅니다.
4. 도착하면 `recharge`로 충전기로 돌려보냅니다. 이 복귀까지가 한 번의 왕복입니다.
5. 이상이 없으면 같은 왕복을 반복해서 횟수를 세어 둡니다. 06 문서의 통과 기준(10회 왕복, 도착 실패 0회)은 예시 숫자이니 현장 사정에 맞게 바꾸세요.

## 확인하지 못한 것

- 이 이동 호출(`custom_call`)로 T300이 실제로 움직이는지는 이 문서를 쓰는 시점에 아직 시험하지 못했습니다. 푸두 문서에는 지원 모델에 PuduT300이 적혀 있습니다.
- 요청의 `call_mode`를 비워 두면 "도착하면 작업이 끝나는 일반 호출"이라고 문서에 적혀 있습니다. 도착 후 로봇이 그 자리에 머무는지 자동으로 돌아가는지는 모릅니다.
