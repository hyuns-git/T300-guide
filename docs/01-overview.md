# 01. 개요

## 구조

T300에 내 PC가 직접 붙지 않습니다. 푸두가 운영하는 클라우드 서버에 인터넷으로 요청을 보내면, 서버가 이미 연결돼 있는 로봇에게 전달하는 구조입니다. 식당에서 주방에 들어가지 않고 홀 직원에게 주문하는 것과 비슷합니다.

```
내 PC (파이썬)  --HTTPS 요청 + 서명-->  푸두 클라우드  -->  T300
```

로봇이 길을 찾고 장애물을 피하는 일은 로봇이 알아서 합니다. 우리가 하는 일은 "어느 로봇을 어느 지점으로 보내라"고 말하는 것입니다.

## 필요한 것

- T300 로봇과, 푸두 맵 도구에서 미리 만들어 둔 맵과 지점
- 푸두 오픈플랫폼 API 키 두 개(`ApiAppKey`, `ApiAppSecret`). 푸두 문서에 따르면 현재는 푸두의 판매사(distributor)와 직영 매장만 신청할 수 있고, 지역 기술지원 담당이 검토합니다. 일반 개인은 푸두 공식 홈페이지의 연락처로 문의해야 합니다.
- 윈도우 PC와 파이썬 3.9 이상

## 이 가이드가 하는 일

푸두 서버에 접속하는 클라이언트를 직접 만들고, 매장과 로봇과 맵 정보를 조회하고, 그 위에 FastAPI와 SQLite로 작은 서버를 올립니다. 클라이언트는 푸두 개발자 문서의 서명 규칙을 보고 작성했고, 조회(GET) 호출만 지원합니다.

## 이 가이드가 아직 하지 않는 일

로봇을 움직이는 호출은 만들지 않았습니다. 코드에도 넣지 않았고, 서버에 GET 외의 메서드가 하나도 없는지를 테스트로 확인합니다. 로봇이 움직이는 작업은 사람이 다칠 수 있어서 현장 승인 절차를 정한 뒤에 추가할 예정입니다.

## 지키는 원칙

1. 조회를 먼저 하고, 조회 결과로 현장 구성을 파악한 뒤에 움직임을 다룹니다.
2. 로봇이 움직이는 시험은 현장 담당자가 입회하고 비상정지에 손이 닿는 상태에서만 합니다.
3. 엘리베이터는 건물 관리 주체나 승강기 업체가 허용한 방법으로만 다룹니다. 건물 안 엘리베이터 제어를 임의로 건드리지 않습니다.
4. 키와 시크릿은 저장소, 채팅, 문서에 값을 적지 않습니다.

## T300 사양 (푸두 공개 자료 기준)

| 항목 | 값 |
|---|---|
| 최대 적재 | 300kg |
| 최고 속도 | 1.2m/s |
| 문턱 / 홈 | 최대 20mm / 최대 35mm |
| 최소 통로 폭 | 60cm |
| 내비게이션 | VSLAM, LiDAR SLAM |
| 적재 모듈 | 표준, 선반, 리프팅, 견인 |

사양은 푸두의 공개 자료를 옮긴 것이고 설치 환경에 따라 다를 수 있습니다. 출처는 [PUDU T300 제품 페이지](https://www.pudurobotics.com/fr/products/pudut300)와 [제품 소개 PDF](https://cdn.robotshop.com/media/P/Pud/RB-Pud-04/pdf/pudu-t300-20240625-presentation.pdf)입니다.
